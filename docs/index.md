# Curso DWES 2026-2027

Apuntes de **Desarrollo Web en Entorno Servidor** del IES Juan de Garay.

## Contenidos

El curso está organizado en diez temas:

1. Introducción al desarrollo web en el servidor.
2. Frameworks y entorno de trabajo con Laravel.
3. Vistas con Blade.
4. Migraciones y modelos.
5. Controladores de Laravel.
6. Desarrollo de un CRUD completo.
7. Validaciones, rutas y mensajes.
8. API REST.
9. Seeders, factories y Faker.
10. Despliegue de aplicaciones web.

Utiliza el menú lateral para abrir los temas y el buscador superior para localizar conceptos, comandos o ejemplos.
